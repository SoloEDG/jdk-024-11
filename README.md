# 静水手记

安装：`npm install`

本地启动：`npm run dev`

Docker 启动：`docker compose up --build`，访问 http://localhost:18224。

类型检查：`npm run typecheck`

## 教学试炼（Teaching Trials）

顶部导航的「教学试炼」是教师工作台：

- **编辑步骤卡**：选饵、二选一分支、指定水域捕获、限时提竿、放流、阶段补给、结业。
  每张卡都可以设置「上一步」，学员能回退重选；已花掉的鱼饵不返还，阶段补给每份课程只领一次。
- **发布前验证**：按真实消耗、回退、分支与补给规则穷尽搜索状态空间。
  - 有完成路径：给出一条可操作示例（逐项库存、实际选择、正式搏鱼力度/泄力）。
  - 无完成路径：列出相互冲突的步骤或资源限制（如“指定鱼饵已用尽”），不会只报“无解”。
  - 搜索触顶：标记为「验证未穷尽」，绝不据此判定无解。
- **版本与进度**：编辑后旧验证失效，需重新验证才能发布。发布新版不会重置进行中的学员，
  他们继续沿原课程版本练习；草稿预览在草稿被修改后会失效。
- **试玩**：使用与正式背包隔离的独立库存；固定遭遇由试炼明示，但耗饵、解锁与搏鱼规则与正式玩法一致。
- **教学记录与徽章**：记录实际选择、失败原因与消耗的鱼饵；毕业徽章只在「有效版本 + 完整通关」后领取一次。

实现要点：

- `src/features/trials/lib/validate.ts`：资源感知的状态空间搜索与冲突定位。
- `src/features/trials/lib/attempt.ts`：试玩状态机（回退、限时、重试、补给、放流）。
- `src/features/trials/lib/versions.ts`：验证/发布、版本固定、徽章结算。
- 搏鱼复用 `src/features/fishing/lib/physics.ts` 的正式物理；验证器会实际模拟固定遭遇是否可收上岸。
